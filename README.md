# Phone Connect Pro — Website starter

This is a responsive dashboard starter for a phone-notification companion project.

## Open locally
Open `index.html` in a browser.

## Deploy
Upload this folder to a GitHub repository and deploy it with Vercel as a static site.

## Important
The dashboard is currently a front-end demo. Live phone alerts require a separately built Android companion app that uses Android's user-approved Notification Access permission and securely sends selected notification data to a backend. WhatsApp notifications may show previews only if the phone's notification settings permit them. This project does not bypass WhatsApp security, read chats directly, or use QR linking.

Next components:
- Android companion app
- Secure user authentication and device pairing
- Backend/WebSocket or push channel
- Notification filtering and privacy controls
